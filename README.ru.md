## Описание

Большинство утилит для заметок на рабочем столе работают на тяжелых веб-движках (Chromium/Electron), потребляя от 200 до 500 МБ оперативной памяти в режиме ожидания.

**NotionDesk** спроектирован как нативное приложение C# / .NET 9 для Windows:
- **Минимальное потребление ресурсов**: расход памяти в пределах 25–40 МБ и 0% фоновой нагрузки на процессор.
- **Нативная производительность**: быстрый рендерер WPF с аппаратным ускорением и контролем памяти.
- **Полная автономность**: отсутствие веб-движков, сбора телеметрии и внешних сетевых сервисов.

## Возможности

- **Полноэкранный Drag & Drop**: перетаскивание файлов `.md` или `.txt` в любую точку окна виджета.
- **Отслеживание изменений файла**: мгновенное обновление текста при сохранении в стороннем редакторе (VS Code, Obsidian, Блокнот).
- **Копирование команд терминала**: распознавание блоков кода PowerShell, Bash и консольных команд с копированием в один клик.
- **Кликабельные ссылки**: распознавание URL (`http://`, `https://`) и Markdown-ссылок с открытием в системном браузере.
- **Системный трей Windows**:
  - Фоновый значок в области уведомлений.
  - Создание новых окон заметок.
  - Быстрое скрытие и отображение всех заметок.
  - Переключение языка интерфейса (Русский / Английский).
  - Управление автозагрузкой Windows через реестр.
- **Мульти-заметки**: независимые окна с сохранением персональных координат и размеров на рабочем столе.
- **Закрепление поверх окон**: режим Always-on-Top для постоянной видимости при работе в других программах.
- **Смена шрифта**: переключение между стандартным пропорциональным и моноширинным (Cascadia Code / Consolas).

## Варианты поставки и установка

Доступны две конфигурации сборки:

1. **Framework-Dependent (~700 КБ)**: ультракомпактный исполняемый файл. Требует установленного [.NET Desktop Runtime 9.0](https://dotnet.microsoft.com/download/dotnet/9.0).
2. **Self-Contained (~65 МБ в zip)**: полностью автономный архив со встроенным рантаймом .NET 9. Работает на любой чистой системе Windows 10/11 без предварительной установки зависимостей.

Скачайте релиз со страницы [Releases](https://github.com/Lychqq/NotionDesk/releases).

### Варианты запуска

- **Портативный режим**: распакуйте архив и запустите `NotionDesk.exe`.
- **Установка через скрипт**: запустите `Install.bat` для развертывания в `%LOCALAPPDATA%\Programs\NotionDesk` с созданием ярлыков.
- **Удаление**: запустите `Uninstall.bat`.

## Управление

| Элемент / Клавиша | Действие |
| :--- | :--- |
| **Drag & Drop файла** | Перетащите `.md` или `.txt` в любое место окна |
| **Шапка окна** | Перемещение окна по рабочему столу |
| **Уголок изменения размера** | Изменение габаритов окна в правом нижнем углу |
| `+` | Открыть дополнительное окно заметки |
| `📁` | Выбрать файл через стандартный проводник |
| `📝` | Открыть текущий файл во внешнем редакторе |
| `📌` | Закрепить окно поверх остальных |
| `RU / EN` | Переключить язык интерфейса |
| `Aa` | Переключить шрифт (пропорциональный / моноширинный) |
| `✕` | Закрыть текущее окно |
| **Иконка в трее** | Двойной клик — скрыть/показать все; правый клик — контекстное меню |

## Сборка из исходников

### Требования

- Windows 10 / 11 (x64)
- [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0)

```powershell
# Клонирование репозитория
git clone https://github.com/Lychqq/NotionDesk.git
cd NotionDesk\DesktopNotes

# Запуск в режиме разработки
dotnet run

# Сборка компактного бинарника (~700 КБ, Framework-Dependent)
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o "../publish"

# Сборка автономного дистрибутива (Self-Contained)
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true -o "../publish_standalone"
```
